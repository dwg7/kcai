# AGENTS

このインスタンスは kcai 原則に従います。

- 踏み跡（旧称「知識の塊」）は Markdown + YAML フロントマターで管理する
- 出典のない断定はしない
- 一次資料本文の転載をしない
- AI 支援の有無を `authors` に記録する
- 判断が割れる場合は `DECISIONS.md` に記録する
- 提案は、公開された資料と、個人として公開してよい経験に限る。所属組織の中の知識を求めない
- 宣伝や勧誘をしない。組織の公式な取り組みや、誰かの推薦を受けたものとして示さない
- 閉じた環境でも読める版付きの配布物を用意する（kcai の `docs/distribution.md`）
