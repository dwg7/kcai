# 語り得ぬこと

kcai の知識は、**公開できる情報だけ**で構成される（`PRINCIPLES.md` の原則 7）。したがって、公開情報に現れにくい知識（事前相談で実際に何が問われるか、審査の勘所、窓口の運用、暗黙の経験則など）は、kcai の知識の**範囲外**になる。これを「**語り得ぬこと**」と呼ぶ。

## 扱い方

1. **推測で埋めない。** 公開情報に根拠がない記述は、書かない。AI が「ありそうなこと」を補うと、出典のない断定になる。
2. **範囲外であることを明示する。** 塊に `unsaid` タグ（値は、語り得ぬことを表す短い識別子の配列）を付け、本文に「語り得ぬこと」の節を置いて、公開情報が届く範囲と届かない範囲の境目を書く。
3. **境目も知識である。** どこまでが公開情報で確かめられ、どこから先が実務者の経験に依存するかを示すことは、読者にとって有用で、確認者（実務者）に何を確認してもらうべきかも示す。
4. **実務者の知識は、別の形で取り込める。** 実務者が自ら公開してよいと判断した内容（講演、論文、公開資料）は、出典として扱える。非公開の経験は、取り込まない。

## 集計

`python3 scripts/build_index.py --tag unsaid` で、語り得ぬこととして明示された領域の一覧を取り出せる。インスタンスの管理者は、この一覧を、実務者による確認の依頼先の候補や、公開資料の探索の課題として使える。
