# タグと関係の慣習（実態の記録）

この文書は、**規範ではなく、実態の記録**です。タグも関係の種類も自由に追加できます（`PRINCIPLES.md` の原則 9）。新しいタグを作る前に、`python3 scripts/build_index.py --stats` で既存の使われ方を確かめ、近いものがあれば再利用してください。

## よく使われているタグ（最初のインスタンスの例）

| タグ | 値の例 | 意味・使い方 |
|---|---|---|
| `layer` | `foundation` / `new-technology` / `reference` | 知識の層。基礎（手法が変わっても通用する土台）、新しい技術（価値を生む）、原典の整理 |
| `freshness` | `high` | 更新が速い出典に依拠している（数か月で変わりうる）。再確認の優先度の目印 |
| `as_of` | `2025-03-31` | 塊の内容が、いつの時点の情報か（`updated` は書いた日） |
| `finding` | `calibration-policy-differs-by-product` | 複数の出典を読み合わせて得た**発見**（予想外の食い違い、見落とされやすい違い）。値は短い英語の識別子 |
| `hazard` | `mixed-height-datums` | 実務で事故につながりうる点（版の混在、ツールの不具合など） |
| `pattern` | `adoption-path` | 複数の事例に共通する型（仮説の場合は、識別子の末尾に `-hypothesis` を付ける慣習） |
| `unsaid` | `pre-consultation-questions-in-practice` | **語り得ぬこと**。公開情報では確かめられず、範囲外とした領域（`docs/unsaid.md`） |
| `layer` の追加値 | `practice` / `map` / `route` | 実務の知識（手続、検定など）、地図、入手経路 |

## よく使われている関係の種類（`relations`）

| 種類 | 意味 |
|---|---|
| `basis` | この塊が前提・根拠とする塊 |
| `impacts` | この塊の内容が変わると、見直すべき塊 |
| `contrasts` | 対比の相手 |
| `supersedes` | 置き換える旧い塊（旧い塊は削除せず `deprecated` にする） |
| `parent` / `child` | 上位／下位 |
| `see-also` | 参照（上のどれにも当てはまらない、緩い関連） |

## 書き方

- キー: 英小文字で始め、英小文字・数字・`_`・`:`・`-`。名前空間を分けたいときは `:` を使ってよい（例: `quality:method`）。
- 値: 1 つの文字列、または `- 値` の配列。同じキーを重複して書かない。
- 迷ったら書く。後から集計で整理できる。
