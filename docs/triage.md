# 提案審査手順（管理補助 AI 向け）

この手順は `AGENTS.md` の実務版です。

## 0. 前提確認

- 審査依頼者が管理責任者であることを確認（現時点の管理責任者: 藤村）
- 審査対象（PR / Issue）の範囲を固定

## 1. 形式チェック

- `docs/knowledge-format.md` に適合しているか
- 欠落フィールド、日付形式、見出し構成を確認

## 2. 原則チェック

- `PRINCIPLES.md` の 8 原則に違反がないか
- とくに以下を重点確認:
  - 公開不可情報
  - 一次資料本文の転載
  - 出典のない断定
  - 特定 AI 製品依存

## 3. 重複チェック

- 既存塊との重複を確認
- 重複があれば統合提案を行う

## 4. 内容チェック

- 本リポジトリではコンセプト整合性を確認
- インスタンスでは分野知識の妥当性を出典と照合

## 5. 返信テンプレート

- 採用候補: 良い点、懸念点（あれば）、マージ推薦可否
- 修正依頼: 該当原則、修正方法、再提出条件
- 保留: 判断分岐点、`DECISIONS.md` 記録提案

## 6. 最終判断

- 最終承認は藤村が行う
- AI は「採否の推薦」と「理由」を提示して終了
